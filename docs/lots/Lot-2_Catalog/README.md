# Lot 2 — Catalogue

## Objectif

Décrire les produits et leurs références commerciales.

## Dépendances

Lots 0-1

## Epics

- Epic 2.1 — Catégories: Créer, renommer et désactiver les catégories
- Epic 2.2 — Produits: Codes, conditionnements, formes et statuts
- Epic 2.3 — Prix et coûts: Money, coût de référence, prix et audit
- Epic 2.4 — Cycle de vie et recherche: Activation, trackInventory et recherche

## Definition of Done

- Toutes les Epics satisfaites.
- Invariants et frontières testés.
- Lint, typecheck, tests et build réussissent.
- Statut et documentation synchronisés.
