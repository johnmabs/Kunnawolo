# Lot 1 — Organisation et Identity Access

## Objectif

Créer organisation, boutiques, membres, rôles et périmètres.

## Dépendances

Lot 0

## Epics

- Epic 1.1 — Organisation: Créer et paramétrer l organisation
- Epic 1.2 — Boutiques: Gérer boutiques, codes, coordonnées et statuts
- Epic 1.3 — Comptes et adhésions: Séparer compte et membership; invitation et activation
- Epic 1.4 — Rôles et affectations: Appliquer OWNER, MANAGER, CASHIER et périmètre boutique

## Definition of Done

- Toutes les Epics satisfaites.
- Invariants et frontières testés.
- Lint, typecheck, tests et build réussissent.
- Statut et documentation synchronisés.
