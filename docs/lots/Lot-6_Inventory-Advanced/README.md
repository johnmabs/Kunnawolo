# Lot 6 — Inventaire avancé

## Objectif

Traiter pertes, comptages et ajustements avec traçabilité.

## Dépendances

Lots 0-5

## Epics

- Epic 6.1 — Pertes de stock: Casse, vol, expiration, coût snapshoté
- Epic 6.2 — Sessions inventaire: Ouvrir, compter et clôturer
- Epic 6.3 — Ajustements: Transformer les écarts en mouvements
- Epic 6.4 — Rapprochement: Détecter les divergences

## Definition of Done

- Toutes les Epics satisfaites.
- Invariants et frontières testés.
- Lint, typecheck, tests et build réussissent.
- Statut et documentation synchronisés.
