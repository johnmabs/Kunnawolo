# Lot 5 — Transferts inter-boutiques

## Objectif

Déplacer le stock via un transit explicite et traçable.

## Dépendances

Lots 0-4

## Epics

- Epic 5.1 — Brouillon: Source, destination et lignes valides
- Epic 5.2 — Expédition: Décrément source et mise en transit
- Epic 5.3 — Réception: Crédit destination idempotent
- Epic 5.4 — Annulation et écarts: États terminaux, motifs et historique

## Definition of Done

- Toutes les Epics satisfaites.
- Invariants et frontières testés.
- Lint, typecheck, tests et build réussissent.
- Statut et documentation synchronisés.
