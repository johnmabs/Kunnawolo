# Lot 3 — Fondations inventaire

## Objectif

Maintenir un stock fiable par boutique-produit avec journal immuable.

## Dépendances

Lots 0-2

## Epics

- Epic 3.1 — Niveaux de stock: StockLevel par boutique et produit
- Epic 3.2 — Mouvements: Journaliser chaque variation
- Epic 3.3 — Entrées et initialisation: Initialiser et réapprovisionner explicitement
- Epic 3.4 — Consultation et alertes: Disponibilité, vues et seuils bas

## Definition of Done

- Toutes les Epics satisfaites.
- Invariants et frontières testés.
- Lint, typecheck, tests et build réussissent.
- Statut et documentation synchronisés.
